# Anish Udupa N — Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy with GitHub Pages
1. Create a new public repository (for example, `anishudupan.github.io`).
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, select deploy from the `main` branch and `/ (root)`.
4. GitHub Pages will publish the site at `https://anishudupan.github.io`.
